#Descripción breve del proyecto

Este proyecto consiste en el desarrollo de un sitio web informativo
sobre los fundamentos de la programación del lado del servidor con PHP.
Su propósito es explicar mediante ejemplos prácticos el uso de
variables, estructuras de control, arreglos y sesiones.

#Temas implementados

Arreglos, bucles, condicionales, sesiones y declaración de variables en PHP.
